# 2048

The classic tile game, rebuilt with care. Four color themes, undo, three board sizes, and synthesized sound. No image or audio assets: every visual is CSS, every sound is generated by the Web Audio API.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. For a production build, use `npm run build && npm start`.

## Play

- Move with the arrow keys, WASD, or a swipe on the board.
- `Z` takes back the last move, up to 3 moves.
- Reach 2048 to win, then keep playing for a higher score.
- Boards come in 3×3, 4×4, and 5×5. Best score is tracked per size.

## Details

- **Themes.** Classic (warm cream), Midnight (neon on near-black), Pastel (soft lavender), Mono (sharp grayscale). Your choice is saved in `localStorage`; the first visit follows the OS color scheme with no flash. Hovering a theme in the switcher previews it before you commit.
- **Motion.** One motion language: tiles slide on a single easing curve, spawns spring in, merges pop with a glow flash and a counting label. The score counts up with a floating `+N` chip. Undo fades the restored tiles back in. New games crossfade out the old board before the new tiles stagger up. `prefers-reduced-motion` replaces all of it with simple fades and skips the confetti.
- **Sound.** Off by default; toggle it in the header. Slide whoosh, merge chime that rises in pitch with the tile value, a short win fanfare, and a low game-over tone. All under 320 ms and debounced so fast moves stay clean.
- **Access.** Keyboard and touch controls behave identically. A live region announces moves, merges, and score changes. Controls are labeled with visible focus rings. Guards ask before a new game or size change throws away a game in progress.

## Structure

```
src/
  app/                  layout, page, and the four theme token sets in globals.css
  components/
    game/               Board, Tile, ScoreBoard, Controls, ThemeSwitcher,
                        SoundToggle, BoardSizeControl, GameOverModal,
                        ConfirmDialog, Confetti, GameShell
    ui/                 button, dialog, alert-dialog, popover, tooltip
  hooks/                use-count-up (score and merge label tweens)
  lib/game/
    engine.ts           pure game rules: slide, merge, spawn, win and lose checks
    use-game.ts         state, undo stack, persistence
    sound.ts            Web Audio synthesis
    themes.ts           theme metadata for the switcher and confetti
    storage.ts          safe localStorage helpers
```

All game rules live in `src/lib/game/engine.ts` as pure functions with no React imports, so they can be unit tested directly.
